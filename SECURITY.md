# Security Policy

## Supported Versions

We provide security updates for the latest released version of PowerSearch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The PowerSearch team takes the security of our extension and our users' privacy very seriously. Because PowerSearch interacts with browser tabs and local page text, maintaining local isolation and strict permissions boundaries is essential.

If you believe you have discovered a security vulnerability or privacy flaw in PowerSearch:

1. **Do NOT open a public GitHub issue.**
2. Send an email to `husainlabwork@gmail.com` with the subject line:  
   `[SECURITY VULNERABILITY] PowerSearch - <Brief Description>`.
3. Please include:
   - Detailed description of the vulnerability.
   - Proof-of-concept code, steps, or reproduction scenario.
   - The affected browser version(s) and operating system.
   - Any potential impact on user data or browser execution.

## Our Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will verify and assess the vulnerability severity.
- If confirmed, we will develop and test a fix.
- We will coordinate public disclosure and release a patched version on GitHub and the Chrome Web Store.
- We will give appropriate credit to the reporter in our release notes (unless anonymity is requested).

Thank you for helping keep PowerSearch and its users safe!
